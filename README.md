# Money With AI: static mirror

This repository holds only the **built public website** of [moneywithai.net](https://moneywithai.net): the same
HTML, CSS, JavaScript and JSON files anyone can download from the live site. It is a standby copy on a second,
independent host (GitHub Pages) so the site stays reachable if the main host has a problem.

- Generated automatically. Do not edit by hand; changes are overwritten on the next publish.
- No source code, no form submissions, no personal data and no secrets live here.
- Download counts are a dated snapshot (`site/api/copies.json`). Forms open your email app instead of posting.
- The General Sans font is not stored here (its licence allows self-hosting, not redistribution through a
  repository). It is fetched from Fontshare when the site is deployed.
- `.github/workflows/uptime.yml` checks the live site every 15 minutes and opens an issue if it is down.
