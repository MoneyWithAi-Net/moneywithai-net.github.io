Steps

  1. Add the 5 bots in the stack: Startup QA Bot, Tech Lead, Support Ticket Fixer, Ship Note and Tickets To Changelog.
  2. Connect the tools they use, starting with GitHub, Slack, Ferndesk, Axiom, Infisical; the full list is below.
  3. Write a short brief: who you serve, what you sell and what each bot must never do.
  4. Run each bot once, in the order shown in the flow, and check every output by hand.
  5. Fix instructions where results were off, then run the whole flow end to end.
  6. Schedule the routine parts and keep an approval step before anything reaches a customer.
