Who It's For

What It Does

How to Set It Up

Time to Set Up
About 2 to 4 hours (our estimate)
Difficulty

Tools Needed
  • Grok Bot: Grok Bot account needed
  • n8n: Free to self-host; n8n Cloud is paid
  • OpenAI: Pay as you go (API billed per token)
  • Telegram: Free plan available
  • Intercom: Paid plan
  • GitHub: Free plan available
  • Zendesk: Paid plan
  • Notion: Free plan available
  1. Add the 4 bots in the stack: Telegram Docs Support Bot, Help Center Updater, Tickets To Changelog and Support Docs Sync.
  2. Connect the tools they use: OpenAI, Telegram, Intercom, GitHub, Zendesk and Notion.
  3. Write a short brief: who you serve, what you sell and what each bot must never do.
  4. Run each bot once, in the order shown in the flow, and check every output by hand.
  5. Fix instructions where results were off, then run the whole flow end to end.
  6. Schedule the routine parts and keep an approval step before anything reaches a customer.
