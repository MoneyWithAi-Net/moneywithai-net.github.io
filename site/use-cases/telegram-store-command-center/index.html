Steps

  1. Add the 4 bots in the stack: Telegram Shopify Order Check, Big Order Slack Alert, Store Manager and Shopify Bot.
  2. Connect the tools they use: Shopify, Telegram, OpenAI and Slack.
  3. Write a short brief: who you serve, what you sell and what each bot must never do.
  4. Run each bot once, in the order shown in the flow, and check every output by hand.
  5. Fix instructions where results were off, then run the whole flow end to end.
  6. Schedule the routine parts and keep an approval step before anything reaches a customer.

Tips and pitfalls

  • Test on a few orders before running it on all of them.
  • Keep refunds and price changes behind approval.
  • Keep it small at first: one bot running well beats five half set up.
