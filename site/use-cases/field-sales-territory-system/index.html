Who it's for

  • Field reps and owners who sell in person

What it does

  • Plant Field OS: Builds the daily plan, base map and site audits.
  • Meeting Brief: Preps each visit.
  • Post Call Assistant: Drafts follow-ups after each visit.
  • Deal Desk Autopilot: Flags stalled opportunities.

How it helps your business

  • Managers see the same picture as reps.

How to set it up

Time to set up

Tools needed

Steps

  1. Add the 4 bots in the stack: Plant Field OS, Meeting Brief, Post Call Assistant and Deal Desk Autopilot.
  2. Connect the tools they use: Gmail and Google Calendar.
  3. Write a short brief: who you serve, what you sell and what each bot must never do.
  4. Run each bot once, in the order shown in the flow, and check every output by hand.
  5. Fix instructions where results were off, then run the whole flow end to end.
  6. Schedule the routine parts and keep an approval step before anything reaches a customer.

Tips and pitfalls

  • Feed it accurate product facts; it repeats what it is given.
  • Get consent before recording any call.
  • Start with one customer segment and add more only when the flow runs cleanly.
