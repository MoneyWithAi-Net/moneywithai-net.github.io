Help Center Updater

After each merged code change, checks whether help articles need an update and drafts the change.

What it does

  • Watches merges.
  • Spots user-facing changes.
  • Drafts articles.
  • Adds screenshots.

Who it's for

  • Founders
  • Developers
  • Small support teams

Set it up 5 steps

  • Grok Bot – Grok Bot account needed
  • Intercom – Paid plan
  • GitHub – Free plan available
  1. 1Read the creator's post with Get it to see how they run it.
  2. 2In Grok Bot, create a new bot whose one-line job is to check each merged pull request for user-facing changes and draft Intercom article updates.
  3. 3Write its instructions in your own words, covering what counts as a user-facing change, how to find related articles, your article style and the rule that drafts wait for approval.
  4. 4Connect GitHub for your repository and Intercom with an admin account, and give it a test login for screenshots.
  5. 5Merge a small visible change on a test branch and check the draft it produces.
Worked exampleA renamed settings page

Example only: an illustration of how a session could go, not a real client, case or result.

  1. A pull request renaming Billing to Plans and Billing is merged.
  2. The bot sees the change affects a menu customers use.
  3. It finds two Intercom articles that mention the old name.
  4. It drafts updates with new screenshots from the test account.
  5. You approve and the articles are updated.
