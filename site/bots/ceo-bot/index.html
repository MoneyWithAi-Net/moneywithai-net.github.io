Example only: an illustration of how a session could go, not a real client, case or result.

  1. You run a website rebuild, a newsletter launch and a hiring push.
  2. Each has a project manager bot.

  4. It brings you one decision: delay the newsletter or cut its scope.
  5. You choose to cut scope and it updates the plan.
