Example only: an illustration of how a session could go, not a real client, case or result.

  1. You hand the orchestrator five small bug fixes.
  2. It starts a cloud agent run for each one.
  3. One run stalls waiting on a missing test file and it chases it.
  4. Four runs finish with passing tests; one needs your decision.
  5. You get one report listing all five results.
