Release To Social Campaign

Turns GitHub product releases into social campaigns in Postiz with approval in Slack.

Set it up with the steps on this page.

What it does

  • Reads GitHub releases.
  • Drafts posts in Postiz.
  • Asks for Slack approval.
  • Schedules approved posts.

Who it's for

  • Developer tool companies
  • Open source maintainers
  • Product marketers

Set it up 4 steps

  • Grok Bot – Grok Bot account needed
  • GitHub – Free plan available
  • Postiz – Check the vendor's pricing
  • Slack – Free plan available
  1. 1In Grok Bot, create a new bot whose one-line job is to turn each new GitHub release into social posts drafted in Postiz, with approval in Slack.
  2. 2Write its instructions in your own words, covering which repos to watch, which platforms to post on, your tone and that nothing is scheduled without a yes in Slack.
  3. 3Connect GitHub, Postiz and Slack, and keep scheduling behind your approval.
  4. 4Run it on your latest release and read the drafts.
Worked exampleA new version release

Example only: an illustration of how a session could go, not a real client, case or result.

  1. Your team publishes version 2.4 on GitHub.
  2. The bot reads the release notes.
  3. It drafts an X post, a LinkedIn post and a short thread in Postiz.
  4. It asks for approval in your Slack channel.
  5. You approve and Postiz schedules them.
