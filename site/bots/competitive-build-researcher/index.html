What it does

  • Researches competitors.
  • Summarises findings.
  • Writes a build plan.
  • Starts a repository.

Who it's for

  • Indie developers
  • Small product teams
  • Founders

Set it up 4 steps

  • Grok Bot – Grok Bot account needed
  • Perplexity – Pay as you go or paid plan
  • GitHub – Free plan available
  1. 1In Grok Bot, create a new bot whose one-line job is to research competing products with Perplexity before a build, then turn the findings into a plan and starter code in a GitHub repository.
  2. 2Write its instructions in your own words, covering how to compare rivals, which sources count, a stop point for your approval after research and the rule that code goes to a branch for review.
  3. 3Connect Perplexity for research and GitHub with access to one new repository only.
  4. 4Run it on a small idea and read every cited source and commit before trusting it further.
Worked exampleResearching a habit tracker

Example only: an illustration of how a session could go, not a real client, case or result.

  1. You ask for a study of habit tracking apps before building one.
  2. It uses Perplexity to compare five apps on features and pricing.
  3. It notes that users often complain about forced subscriptions.
  4. You approve an idea for a one-time purchase tracker.
  5. It creates a GitHub repository with a plan and starter files.
