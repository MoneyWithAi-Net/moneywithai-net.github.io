What it does

  • Reads plan sets.
  • Flags likely issues.
  • Marks up sheets.
  • Builds a review package.

Who it's for

  • Architects and drafters
  • Contractors
  • Permit consultants

Worked exampleA small commercial fit-out

Example only: an illustration of how a session could go, not a real client, case or result.

  1. You upload a ten-sheet plan set for a cafe fit-out.
  2. The bot flags a missing door swing and an unlabeled exit sign.
  3. It notes that one wall type has no detail reference.
  4. It builds a review package with each markup listed by sheet.
  5. A licensed reviewer checks the package and makes the final call.
