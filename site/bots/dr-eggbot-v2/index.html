What it does

  • Asks preference questions then creates bots via CreateAgent
  • Applies poteto-mode for coding bots (one job, unslopped, verified)
  • Designs non-coding bots with one job, one voice, explicit anti-jobs, no leftover tools
  • Uses design-grok-bot skill for consistent quality
  • Integrates pstack, verification skills, and healthchecks
  • Creates custom UIs via Make Bot UI skill

Who it's for

  • Teams wanting well-designed Grok Bots without manual prompt engineering
  • Developers needing coding bots that follow poteto-mode standards
  • Non-technical users creating specialist bots with proper anti-jobs
  • Organizations standardizing bot architecture across their fleet
  • Anyone migrating from other AI platforms

Questions

What is poteto-mode?

An agent style emphasizing concise detailed responses, deliberate subagents, unslopped prose, simple code, and verified work.

Does it create shareable templates?

Not by default. It creates custom bots for your specific need. When a bot stages a public template, it includes the full live profile.description.

What are the standing healthchecks?

transcript-healthcheck runs weekdays at 8:44 PT for friction scan; routine-healthcheck runs Mondays at 8:49 PT for token/waste audit.

Can it create non-coding bots?

Yes. Non-coding bots get one job, one voice, explicit anti-jobs, and no leftover tools — same tightness as poteto-mode.
